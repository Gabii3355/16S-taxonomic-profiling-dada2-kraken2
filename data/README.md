# Data

## Dataset overview

This project uses publicly available 16S rRNA amplicon sequencing data.

| Property | Value |
|---|---|
| Sample accession | SRR13569534 |
| Sequencing platform | Illumina |
| Read type | Paired-end |
| Target gene | 16S rRNA |
| Variable regions | V3–V4 |
| Initial number of read pairs | 67,311 |
| Input format | FASTQ |

The dataset was used for comparative taxonomic profiling with DADA2 and
Kraken2/Bracken in Galaxy.

## Data availability

Raw FASTQ files are not included in this GitHub repository because of their
size.

The data can be obtained using the sample accession:

`SRR13569534`
